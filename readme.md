Handwritten Digit Recognition

Introduction
Handwritten Digit Recognition is a Machine Learning project that identifies handwritten numbers from images.
This project uses the MNIST dataset to train a neural network model. It can recognise handwritten digits from 0 to 9.
The user can upload an image of a handwritten digit, and the trained model predicts which number is present in the image.

Objective
The main objective of this project is to develop a machine learning model that can recognise handwritten digits from 0 to 9.
It aims to:
- Train a model using the MNIST dataset.
- Understand image preprocessing.
- Predict handwritten digits from uploaded images.
- Learn how neural networks work in image recognition.

Technologies Used
- Python
- TensorFlow
- NumPy
- Matplotlib
- Pillow
- VS Code

Dataset
This project uses the MNIST handwritten digit dataset, which contains images of handwritten digits from 0 to 9.
Each image is a 28 × 28 pixel grayscale image.

## Results
the model was successfully trained using the MNIST dataset.
It was able to recognise handwritten digits from uploaded images.
Example:
- Actual Digit: 2
- Predicted Digit: 2
The model successfully recognised the handwritten digit.
